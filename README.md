# eugene-site

Eugene's personal portfolio, built with plain HTML, CSS, and vanilla JavaScript. There is no framework or build step.

The site lives in `public/`. Open `public/index.html` locally to preview it. GitHub Actions publishes that directory to GitHub Pages whenever `main` is updated.

Before publishing personal contact details, replace the clearly marked email, LinkedIn, biography, and location placeholders in `public/index.html`.

`CLAUDE.md` is retained because the original lab asks for that artifact. Codex CLI actually loads the project instructions from `AGENTS.md`.
