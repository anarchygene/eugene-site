# eugene-site: personal portfolio
Plain HTML/CSS plus a little vanilla JavaScript. No frameworks and no build step.
Deploy by pushing to main; GitHub Actions publishes public/ to GitHub Pages.

## Conventions
- Site files live in public/.
- Section ids: #hero #about #skills #projects #repos #contact.
- Keep it responsive, with no horizontal scrolling at 375px.
- Use relative asset paths so the site works under a GitHub Pages repository path.
- Run relevant local checks before committing.
- Do not invent personal details; leave clearly marked placeholders when details
  have not been supplied.
